## 🎮 Tính năng:
- **Dán Code** → AI fix code, check đáp án của code đó, chat với ai những gì thắc mắc, tạo quiz từ code sai
- **Quiz Game** → 3 câu luyện tập + Code viết sai có thể tự tạo để luyện tập lại
- **Nhóm Lớp** → CNTT1/2 + Web21 + Nộp bài
